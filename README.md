# Application Indicateurs Urbains

Application de visualisation des indicateurs urbains des communes de Douala et Yaoundé.

## Structure du projet

- `backend/` - API Flask avec traitement des données Excel
- `frontend/` - Interface utilisateur HTML/JS
- `backend/indicateurs_urbains.xlsx` - Base de données Excel
